# Cigares Casa Hurtado

Site vitrine pour Cigares Casa Hurtado (Carlos Hurtado, Renens VD) — cigares du Nicaragua, en exclusivité en Suisse.

Static site, no build step. French is the main language; DE, EN and ES are available from the switcher (header, age gate, mobile menu).

- `index.html` — page structure
- `css/style.css` — design
- `js/data.js` — catalogue (lines, vitolas, prices, blends) and all FR/DE copy
- `js/scene.js` — the real-time 3D cigar (three.js)
- `js/main.js` — age gate, language, scroll choreography, shop, interactions

Catalogue and prices mirror the WooCommerce store at rhums-cigares.ch (checked 24.09.2026). Order buttons link to the matching product page there.
Photos and product cutouts come from the client's own site; smoke and flame clips are free Mixkit stock footage.
